# KeyLens

AI key lifecycle + spend brain for startups running agents. Finds every AI key
your company has, rotates them on a schedule, and pings you when spend looks
weird. (MVP scaffold - mock mode works with zero external credentials.)

## Quickstart

```bash
pnpm install
pnpm seed      # creates packages/db/data/keylens.db with demo org + story
pnpm dev       # http://localhost:3000
```

See `.env.example` for the (mostly mock) environment. Full docs land here as
the scaffold completes.
